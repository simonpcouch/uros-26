### Slides for uRos 2026 keynote

<a href="https://simonpcouch.github.io/uros-26"><img width="1171" alt="Title slide reading 'Practical AI for data science,' Simon Couch, uRos 2026, on a purple background with two overlapping orange and teal circles." src="figures/hero-rounded.png" /></a>

Source code and slides for "Practical AI for data science," Simon Couch's keynote at uRos 2026. The rendered slides are [here](https://simonpcouch.github.io/uros-26).

* [Posit Assistant](https://assistant.posit.co), a data science coding agent in RStudio, Positron, and the terminal.
* [commons](https://pos.it/commons), an R and Python package for building trustworthy data agents for your collaborators.
* [bluffbench](https://posit-dev.github.io/bluffbench), an eval measuring whether models report what a plot actually shows rather than what they expect to see.
* [bluffbench2](https://github.com/posit-dev/bluffbench2), an eval measuring whether models notice subtle data quality issues in plots.

Some additional citations:

* [Conviviality's spreadsheet hell sinks the business](https://www.accountingweb.co.uk/business/management-accounting/convivialitys-spreadsheet-hell-sinks-the-business), on a beverage company that reported healthy financials for years due to a spreadsheet arithmetic error.
* [A Scientist's Nightmare: Software Problem Leads to Five Retractions](https://www.science.org/doi/10.1126/science.314.5807.1856), on a sign-flipping bug in in-house protein modeling software.
* [About the RStudio Project](https://rstudioblog.wordpress.com/2011/02/27/about-the-rstudio-project/) and [RStudio, new open-source IDE for R](https://rstudioblog.wordpress.com/2011/02/28/rstudio-new-open-source-ide-for-r/), the 2011 posts announcing RStudio as a tool for analysis that is both trustworthy and intuitive.
* Research on human-AI collaboration: Vaccaro et al. (2024), ["When combinations of humans and AI are useful: A systematic review and meta-analysis"](https://doi.org/10.1038/s41562-024-02024-1); Crootof et al. (2023), ["Humans in the Loop"](https://scholarship.law.vanderbilt.edu/vlr/vol76/iss2/2/); and Anthropic's writing on approval fatigue in Claude Code, ["How we built Claude Code auto mode"](https://www.anthropic.com/engineering/claude-code-auto-mode) and ["Auto mode is now the default in Claude Code"](https://claude.com/blog/auto-mode-default-in-claude-code).
